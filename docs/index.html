§03 · Magic Grid & Cameo / CATIA Magic

Magic Grid & Cameo / CATIA Magic

The flagship. Magic Grid is the SysML modeling method developed at No Magic (now Dassault Systèmes) and applied in Cameo Systems Modeler / CATIA Magic: a grid of problem/solution domains × structure/behaviour/requirements/parametrics that tells you what to model next. New here? Start with the MagicGrid Book of Knowledge, then open a real model from the Model Gallery. This is the deepest part of the list and the one no other awesome-list covers.

Methodology & guides

The definitive practitioner guide to the MagicGrid method, by Aleksandravičienė & Morkevičius. SysML-general MagicGrid Cameo book (2021).

Open-access PDF of the foundational paper introducing the grid method that became MagicGrid. SysML-general MagicGrid paper (2017).

INCOSE INSIGHT article extending MagicGrid to cover V&V workflows. SysML-general MagicGrid paper (2023).

Systems Architecture Meta-Model for the MagicGrid Framework

§05 · Broader SysML / MBSE Context

Broader SysML / MBSE Context

Curated, not exhaustive: the wider ecosystem any MBSE practitioner runs into. The language (SysML v1, the stable incumbent; SysML v2, the textual successor now in release), the methods to apply it, the architecture frameworks to structure it, the tools to run it, and reusable libraries to build from. Capella and Arcadia-specific resources live in the family spoke awesome-capella.

Specifications & standards

OMG SysML Specification

Canonical OMG SysML spec page; now defaults to v2.0 (2025), with v1.7 the final v1 release. SysML-general spec (2025).

OMG SysML v1.7

The final SysML v1 release; the general-purpose v1 MBSE modeling language. SysMLv1 spec (2024).

Systems-Modeling/SysML-v2-Release

Start here for SysML v2: living release train (latest tag 2026-08) with spec, training, examples, libraries. SysMLv2 spec (2026).

INCOSE Systems Engineering Handbook, 5th Edition

INCOSE SE Handbook v5.0 (2023), Wiley 5th ed; practitioner reference for SE life-cycle processes aligned to ISO/IEC/IEEE 15288. SysML-general standard paid (2023).

OMG KerML Specification

The Kernel Modeling Language spec, the formal semantic foundation underlying SysML v2. SysMLv2 spec (2025).

OMG Systems Modeling API & Services

OMG spec defining platform-independent REST/SOAP/Java APIs for KerML and SysML v2 models. SysMLv2 spec (2025).

OMG SysML v2.0 Specification

The dedicated landing page for the SysML v2.0 language release. SysMLv2 spec (2025).

NASA Systems Modeling Handbook (NASA-HDBK-1009)

Official NASA tool-agnostic guidance on building and using system models. SysML-general standard (2022).

Methodology & method references

Survey of MBSE Methodologies (Estefan, INCOSE/OMG)

The standard comparative reference: OOSEM, Harmony-SE, RUP-SE, Vitech, JPL State Analysis, OPM side by side. SysML-general paper (2008).

OMG MBSE Wiki - Methodology Directory

Master index of MBSE methodologies (OOSEM, SYSMOD, Harmony, Arcadia, and more). SysML-general blog (2024).

OOSEM (OMG MBSE Wiki)

Vendor-neutral reference for the Object-Oriented Systems Engineering Method. SysML-general blog (2023).

SYSMOD (Tim Weilkiens)

Canonical page for the SYSMOD method toolbox: roles, activities, products, and SysML integration. SysML-general blog (2022).

Harmony aMBSE Deskbook (IBM)

The full IBM Harmony agile-MBSE method deskbook, freely available. SysMLv1 Rhapsody book (2020).

FAS Method

Official site for Functional Architectures for Systems (Lamm & Weilkiens), with open publications and plugins. SysML-general blog (2024).

JPL State Analysis

NASA/JPL's primary state-based MBSE method for control-system and mission modeling. SysML-general blog (2023).

Object-Process Methodology (Dori, Technion)

Authoritative overview of OPM (ISO 19450), a self-contained graphical-plus-textual modeling method. SysML-general blog (2022).

SpesML - Open Methodology Docs (TUM/fortiss)

Full open documentation of the SPES-based SpesML method: viewpoints, concepts, case studies, Cameo plugin. SysML-general Cameo blog (2024).

Architecture frameworks

The defence/enterprise architecture frameworks SysML models get built against. UAF is the modern OMG framework: it supersedes UPDM/DoDAF/MODAF and runs natively in Cameo; start there unless a specific programme mandates DoDAF or NAF.

OMG UAF Specification

The Unified Architecture Framework spec hub: Domain Metamodel (DMM) and the UAFML profile Cameo implements. SysML-general spec (2022).

OMG UAF Program Page

OMG's UAF overview and community page: concepts, videos, certification, and adoption guidance. SysML-general blog (2024).

UAF Plugin Documentation (CATIA Magic / No Magic)

Official CATIA Magic / No Magic docs hub for Cameo/MagicDraw plugins, including UAF. SysMLv1 Cameo tutorial (2024).

OMG UPDM Specification

The Unified Profile for DoDAF/MODAF, UAF's predecessor profile, still referenced by legacy programmes. SysML-general spec (2013).

NATO Architecture Framework v4

Official NATO landing page for NAF v4.1, the current NATO architecture framework. SysML-general standard (2020).

DoD Architecture Framework (DoDAF 2.02)

Official US DoD CIO page for DoDAF 2.02, the US defence architecture framework. SysML-general standard (2010).

MOD Architecture Framework (MODAF)

Official UK gov.uk MODAF page; now withdrawn in favour of NAF/UAF but still widely referenced. SysML-general standard (2016).

SysML v2 tooling

SysML v2 Pilot Implementation

OMG reference pilot: Xtext editors, PlantUML visualization, and a Jupyter kernel for SysML v2. SysMLv2 tool (2026).

Eclipse SysON

Open-source web-based SysML v2 modeler (graphical, form, tabular editors), by Obeo and CEA List. SysMLv2 SysON tool (2026).

SysIDE Editor (Sensmetry)

VS Code extension for SysML v2: highlighting, autocompletion, and formatting. SysMLv2 other-tool plugin (2025).

Sysand (Sensmetry)

Open-source package manager for SysML v2 and KerML model libraries. SysMLv2 other-tool tool (2026).

Domain & reusable libraries

Building-block libraries and profiles you import into your own model (units, domain components, frameworks, standard profiles) rather than whole-system reference models.

SysML v2 Standard Library

The normative KerML/SysML v2 standard libraries: ISQ quantities, SI units, geometry, analysis, domain libs. SysMLv2 tool (2026).

SysML v2 Library for AADL

Official SysML v2 rendering of AADL (base types, property sets, component categories) for avionics/embedded. SysMLv2 tool (2026).

SYSMOD for SysML v2

Tim Weilkiens' SYSMOD method as an importable SysML v2 language-extension library, with examples. SysMLv2 tool (2026).

elan8 SysML v2 Domain Libraries

Importable domain building-block libraries (robotics: actuation, control, autonomy, operations). SysMLv2 has-model tool (2026).

QUDT - Quantities, Units, Dimensions & Types

RDF/OWL vocabulary of quantities and units widely reused for units handling in MBSE models. SysML-general other-tool tool (2024).

openCAESAR Metrology Vocabularies

ISO/IEC 80000 quantities-and-units plus JCGM VIM4 metrology, as importable OML libraries. SysML-general other-tool tool (2026).

GfSE SAF Cameo Profile

System Architecture Framework profile, UAF-tracing profile, and library packaged for Cameo. SysMLv1 Cameo plugin (2026).

SCRE Cameo Profiles

Secure Cyber Resilient Engineering profiles for Cameo, built on RAAML and SACM (safety/assurance). SysMLv1 Cameo plugin (2025).

UAF for Papyrus (Adocus)

OMG Unified Architecture Framework profile plus a UAF Measurement Library for Eclipse Papyrus. SysMLv1 Papyrus plugin (2022).

Other MBSE tools

Cameo Systems Modeler / CATIA Magic

Commercial cross-platform MBSE environment: SysML, UML, DoDAF/MODAF, requirements traceability. SysMLv1 Cameo tool paid (2024).

Eclipse Papyrus

Industrial-grade open-source Eclipse modeling tool for UML with full SysML support. SysMLv1 Papyrus tool (2024).

IBM Engineering Systems Design Rhapsody

Commercial MBSE tool: SysML plus the Harmony method, UAF/DoDAF, AUTOSAR, FMI co-simulation. SysMLv1 Rhapsody tool paid (2024).

Gaphor

Modelio

openCAESAR / OML

JPL-originated ontology-based modeling language and OWL toolchain for traceable MBSE, with worked examples. SysML-general other-tool tool (2025).

APIs & automation

SysML v2 API Services

Proof-of-concept REST implementation of the OMG Systems Modeling API & Services spec. SysMLv2 tool (2026).

Official Python client for the SysML v2 Systems Modeling API & Services. SysMLv2 tool (2021).
